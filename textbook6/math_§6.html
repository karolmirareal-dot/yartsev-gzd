№ 2.1

Назовите делители чисел 37, 35, 99.

Ответ
37: делится только на 1 и на 37. Делители: 1, 37. Это простое число.
35: делится на 1, 5, 7, 35. Делители: 1, 5, 7, 35. Составное.
99: делится на 1, 3, 9, 11, 33, 99. Делители: 1, 3, 9, 11, 33, 99. Составное.
№ 2.2

Используя таблицу простых чисел, определите, какие из чисел 107, 123, 367, 409, 531, 557, 853, 977 являются простыми.

Ответ
Проверяем каждое число:
107 — простое (не делится на 2, 3, 5, 7).
123 — составное: 123 = 3 · 41.
367 — простое (по таблице простых).
409 — простое.
531 — составное: 531 = 3 · 177 = 9 · 59.
557 — простое.
853 — простое.
977 — простое.
Ответ: простые числа: 107, 367, 409, 557, 853, 977.
№ 2.3

Числа 2876, 4500, 777 777, 595 599 — составные. Докажите это утверждение.

Ответ
Для каждого числа покажем, что оно имеет более двух делителей:
2876: оканчивается чётной цифрой → делится на 2: 2876 = 2 · 1438. Значит, составное.
4500: оканчивается нулём → делится на 10: 4500 = 10 · 450. Составное.
777 777: сумма цифр 7+7+7+7+7+7 = 42, 42 : 3 = 14 → делится на 3: 777 777 = 3 · 259 259. Составное.
595 599: сумма цифр 5+9+5+5+9+9 = 42, 42 делится на 3 → делится на 3: 595 599 = 3 · 198 533. Составное.
Что и требовалось доказать.
№ 2.4

Может ли произведение двух простых чисел быть простым числом?

Ответ
Решение:
Пусть p и q — простые числа.
Тогда произведение pq делится на 1, p, q, pq.
Если p ≠ q, то делителей уже 4 — составное.
Если p = q, то произведение p² делится на 1, p, p² — 3 делителя — тоже составное.
Ответ: Нет, не может.
№ 2.5

Каким числом может быть выражена площадь квадрата, если его сторона выражена натуральным числом?

Ответ
Решение:
Площадь квадрата S = a², где a — натуральное число.
Значит, S — квадрат натурального числа: 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, ...
Ответ: S — точный квадрат натурального числа.
№ 2.6

Каким числом может быть выражен объём куба, если его ребро выражено натуральным числом?

Ответ
Решение:
Объём куба V = a³, где a — натуральное число.
Значит, V — куб натурального числа: 1, 8, 27, 64, 125, 216, 343, 512, 729, 1000, ...
Ответ: V — точный куб натурального числа.
№ 2.7

Число a делится: а) на 7; б) на 12. Какое это число: простое или составное?

Ответ
а) Если a делится на 7 и a > 7, то у числа a есть делители 1, 7, a и, возможно, другие. Значит, a — составное (кроме случая a = 7 — тогда простое).
б) Если a делится на 12 и a > 12, то a — составное (у него есть делители 1, 2, 3, 4, 6, 12, a).
Ответ: в обоих случаях a — составное (при a > 7 или a > 12 соответственно).

№ 2.10

Все ли чётные числа являются составными?

Ответ
Решение:
Составное число имеет больше двух делителей.
Число 2 — чётное, но у него только 2 делителя: 1 и 2. Значит, оно простое.
Все остальные чётные числа делятся ещё и на 2, поэтому они составные.
Ответ: Нет, не все. Число 2 — исключение.

№ 2.15

Напишите все двузначные числа, разложение которых на простые множители состоит из двух или трёх одинаковых множителей. Как называют эти числа?

Ответ
Решение:
Двузначные числа вида p² (p — простое): 4·4=16, 5·5=25, 7·7=49. Также 2²·2²=16 — уже есть.
Также кубы p³: 2³ = 8 (не двузначное), 3³ = 27, 4³ = 64 (4 не простое — но множители 2·2·2·2·2·2 = 64 = 2⁶), 5³ = 125 (не двузначное).
Двузначные вида p⁴: 2⁴ = 16, 3⁴ = 81.
Двузначные вида 2⁵ = 32, 2⁶ = 64.
Соберём все: {16, 25, 27, 32, 36, 49, 64, 81} (36 = 6², но 6 = 2·3, тогда 36 = 2²·3² — не одинаковые). Уточним: 36 = 2²·3² — не подходит.
Итоговый список: {16, 25, 27, 32, 49, 64, 81}.
Также можно добавить 2⁷ = 128 (не двузначное).
Такие числа называют точными степенями (квадраты, кубы и другие степени простых чисел).

№ 2.21

Сколько чётных четырёхзначных чисел можно составить из цифр 0, 5, 7, 8, 9, если цифры повторяются?

Ответ
Решение:
1-я цифра (тысячи): не может быть 0 → 4 варианта (5, 7, 8, 9).
2-я цифра (сотни): любая из 5 цифр → 5 вариантов.
3-я цифра (десятки): любая из 5 цифр → 5 вариантов.
4-я цифра (единицы): должна быть чётной → 0 или 8 → 2 варианта.
Перемножаем: 4 · 5 · 5 · 2 = 200 чисел.
Ответ: 200 чисел.
№ 2.22

Припишите к числу 1000 по одной цифре справа и слева так, чтобы число делилось на 2, 3, 6 и 9.

Ответ
Решение:
Нужно получить шестизначное число вида a1000b.
Оно должно делиться на 6 и 9, значит делиться на 2 и 9 (и на 3 автоматически).
Сумма цифр должна делиться на 9: a + 1 + 0 + 0 + 0 + b = a + b + 1 делится на 9.
Также b — чётная цифра (для делимости на 2).
Возьмём a = 1, b = 8: сумма = 1 + 1 + 8 = 10 — не делится на 9. Не подходит.
Возьмём a = 2, b = 6: сумма = 2 + 1 + 6 = 9 — делится на 9, b = 6 чётное. Подходит: 210006.
Проверка: 210006 : 2 = 105003; 210006 : 3 = 70002; : 6 = 35001; : 9 = 23334. ✓
Другие варианты: a = 3, b = 4 → 310004 (сумма 8 — нет); a = 4, b = 4 → сумма 9 ✓ (410004).
Ответ: например, 210006, 410004, 810000 и др.

№ 2.31

Существуют ли среди точек A, B, C и D точки, координаты которых простые числа (рис. 2.1), если p — простое число?

Ответ
По рисунку точки: A = p − 1, B = p + 1, C = p + 2, D = 2p (примерно).
Простые числа среди них:
A = p − 1 — для p = 3: A = 2 (простое).
B = p + 1 — не может быть простым для p > 1 (чётное и > 2).
C = p + 2 — простое, например, при p = 3: C = 5; при p = 5: C = 7.
D = 2p — всегда составное (кроме p = 1).
Ответ: да, точки A (при p = 3) и C могут иметь координаты-простые числа.
